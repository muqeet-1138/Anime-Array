What Anime Array is

Anime Array is a free, independent, fan-built platform of AI tools for anime fans. It is a conversational platform, not a streaming service, and it hosts no video of any kind — no episodes, no films, no media files. The platform works because of what it does have: four distinct tools, all free, none requiring an account.

The premise behind it is straightforward. The difficult part of being an anime fan was never finding out what exists. There are already thousands of titles, lists, calendars and trackers. The difficult part is choosing what to watch, and then finding someone to talk to about it afterwards. Anime Array is built around that second problem.

In short

No account required. No paywall. No video. No affiliation with any anime studio, publisher or licensor. Funded by clearly labelled advertising, and user data is never sold.

The four products

Roleplay

Twelve anime characters you can hold real conversations with, each with a distinct voice and temperament.

Otaku AI

A conversational anime assistant with two modes and eight built-in tools for discovery and lore.

AniPick AI

A recommendation engine built from what you actually watched, loved and skipped.

Vision AI

An anime image generator for character art, wallpapers and creative work.

All four are indexed together at the Anime Array AI Hub. Each product is documented in more detail on the products page.

Otaku AI in brief

Otaku AI is the conversational anime assistant that supports the rest of the platform. It answers questions about series, characters, lore and how the site works, and it runs in two modes. Standard Brain is the direct, knowledgeable assistant. Character RP lets it answer in the voice of an anime character instead, which is useful for exploring how a character would react to a given situation.

Eight tools are built in: Recommend Anime, Currently Airing, Mood Match, Anime Search, Character Creator, Anime Quiz, Power Scaling and Philosophy. Conversations can be shared as text, exported, or turned into an image card, and history is saved for signed-in users.

It is available at otaku.animearray.site.

AniPick AI in brief

AniPick AI is a recommendation engine that builds suggestions from what you have already watched, your favourites, and the titles you dropped. Instead of returning the same commercially popular list to everybody, it weighs the specific track record you give it and proposes the next logical step. It is deliberately useful within a single sitting, before any pattern of behaviour has accumulated.

It is available at animearray.site/anipick.

Vision AI in brief

Vision AI is an anime image generator for character art, wallpapers and creative ideas. It sits alongside the conversational tools so that the same platform covers both talking about anime and making it. Available at animearray.site/vision-ai.

How the platform is run

Anime Array is operated by a small independent team, and the decisions behind it follow a short set of rules kept in priority order. They are published rather than implied, because a free site that asks for trust should say what it does with it.

  • It must work on a slow phone on mobile data. Every core feature is tested on a throttled connection before it ships.
  • No account to use the core. Accounts are an opt-in convenience, never a requirement.
  • Readable over clever. A page that is easy to read and repair is worth more than one that scores marginally better on a metric nobody checks.
  • Honest defaults. If a feature can mislead someone about what the site is or how it earns money, that is a defect.
  • Reversible changes. New work should be possible to undo in a single step.
  • Performance is a design decision rather than something recovered afterwards.

Accessibility

Accessibility on this platform is treated as a requirement rather than a feature, and none of it is conditional on having an account. The platform uses semantic HTML so that headings describe a genuine hierarchy and controls are correctly identified. Every interactive element is reachable and operable by keyboard, with a visible focus indicator that does not rely on colour alone. Body and interface text meet or exceed WCAG AA contrast against their actual rendered backgrounds. Every meaningful image carries descriptive alternative text, while decorative images are marked as such so assistive technology skips them rather than announcing noise. Every form field has an associated label that makes sense read aloud, and errors are explained in text rather than signalled by colour alone. Status changes and streaming responses are announced through live regions, and the reduced-motion preference is honoured throughout.

Privacy

Anime Array does not sell user data to anyone, including advertisers. Advertising is the business model and is labelled as such wherever an ad appears. Third-party services are called from the server wherever possible so that API credentials and advertising identifiers are not exposed in page source. Accounts are optional, and every core feature can be used without providing an email address. Analytics are used to understand how the site is used rather than to build a profile of individuals, and site administrators are excluded from reporting so internal traffic does not distort the figures. The full position is set out in the platform's Privacy Policy.

What Anime Array does not do

A short list stated publicly so that nobody has to take it on trust. Anime Array does not host or mirror video, subtitles or any other media. It does not claim affiliation it does not have: no studio, publisher, licensor, network or distributor has endorsed, licensed, sponsored or approved this project. It does not use voice cloning, and no character's dialogue is spoken by a real person in real time. It does not sell or broker personal data. It does not charge for a core feature. And it does not use dark patterns — there are no fake download buttons, fake play buttons, countdown timers or misleading prompts anywhere on the platform.

Corrections, copyright concerns and content questions are handled directly through the contact form.

Getting started

Nothing needs to be installed and no account needs to be created. Open the main site, pick a character from the roleplay platform and start talking, or go straight to Otaku AI and ask something. If you would rather begin with a recommendation, AniPick AI needs three pieces of input and nothing more: what you watched lately, your all-time favourites, and anything you skipped. More context about the project is on the about page, and the common questions are answered on the FAQ.
